# fidgets

一些能上手玩的前端小效果，每个一个文件夹，零依赖（个别效果可选接一个物理库），打开 `index.html` 就能玩。

Small, fidgety front-end effects. One folder each, zero dependencies, open `index.html` to play.

| 效果 | 说明 |
|---|---|
| [弹弹乐 · avatar-fling](./avatar-fling/) | 拽住聊天头像拉成果冻，松手弹回或弹弓甩飞，带小球物理和冒回动画 · [在线玩](https://zziying.github.io/fidgets/avatar-fling/) |
| [河豚 · avatar-puff](./avatar-puff/) | 长按自己的头像分几口气鼓成两倍大，再长按像撒气的气球乱窜缩没、原位冒回 · [在线玩](https://zziying.github.io/fidgets/avatar-puff/) |
| [哒哒哒 · bubble-gun](./bubble-gun/) | 把一条气泡拆成字机关枪射对方头像，打中的字掉一地还能拖 · [在线玩](https://zziying.github.io/fidgets/bubble-gun/) |
